# backlog

[In English](README.md)

Скилл для Claude: задачи проекта лежат в репозитории обычными файлами. Сделан для работы, которую
делят владелец-человек и один или несколько агентов разработки.

- По файлу Markdown на открытую задачу, с несколькими полями: приоритет, исполнитель, насколько
  агент справится сам, оценка.
- Сводка `INDEX.md`, которую собирает скрипт. Она отвечает на три вопроса: где нужен владелец, что
  агент сделает быстро, что можно оставить на ночь.
- Inbox для идей одной строкой и журнал закрытых задач по месяцам.
- Один скрипт на Python, только стандартная библиотека, лежит в самом проекте. После установки
  ничего не зависит ни от скилла, ни от Claude: беклогом пользуется любой агент или человек.

Схема взята из живого проекта: несколько клиентов на общем ядре, около 300 открытых задач, сессии
агентов на двух машинах разом.

## Как это выглядит

```
backlog/
  INDEX.md            собирает скрипт: нужен владелец / быстрое / на ночь
  api.md  web.md      собирает скрипт: все открытые задачи области, по строке
  api/API-001.md      открытая задача
  web/WEB-001.md
  inbox.md            идеи, по строке
  done/2026-10.md     закрытые задачи, по строке
  config.json         области, исполнители, места, метки, заморозка
  README.md           правила, на языке проекта
tools/backlog.py      скрипт
```

Задача:

```markdown
---
id: API-002
title: Слать недельную сводку со стенда
priority: P2
executor: claude
autonomous: yes
effort: 1h
where: any
due:
tags: []
related: []
after: [GEN-001]
created: 2026-10-04
from: разбор почтового модуля
---
Что сделать — один-три абзаца.

**Готово, когда:** проверяемый выход.
**Контекст:** чем подтверждено, почему важно.
**Материалы:** `src/mail/digest.py:40`, журналы, документы.
```

Сводка по шести таким задачам, с сокращениями:

```markdown
## Нужен владелец — 2

### Решить — 1

- [GEN-002](other/GEN-002.md) · P2 · 5m · Решить: оставить или убрать тёмную тему

### Сделать или дать доступ — 1

- [GEN-001](other/GEN-001.md) · P2 · 10m · Завести учётную запись стенда у почтового провайдера

### Агент делает, в конце — владелец — 1

- Сайт: [WEB-001](web/WEB-001.md)

## Быстрое: агент сам, до 1 ч — 1

## На ночь — 1

[API-001](api/API-001.md) 2h
```

`API-002` нет ни в одном списке: она идёт после (`after`) задачи владельца `GEN-001` и встанет в
них, когда та будет закрыта.

## Установка

**Claude Code, плагином:**

```
/plugin marketplace add poznik/backlog-skill
/plugin install backlog@backlog-skill
```

**Claude Code, личным скиллом:**

```bash
git clone https://github.com/poznik/backlog-skill
cp -r backlog-skill/skills/backlog ~/.claude/skills/backlog
```

**Приложения Claude:** файл `backlog.skill` из
[последнего выпуска](https://github.com/poznik/backlog-skill/releases/latest) добавить в настройках
скиллов.

**Без Claude:** установщик и скрипт — обычный Python 3.8+.

```bash
python backlog-skill/skills/backlog/scripts/init_backlog.py --root <проект> --lang ru \
    --area api:API:"Сервер" --area web:WEB:"Сайт" --area other:GEN:"Иное"
```

## Как пользоваться

В проекте скажите, что нужно:

- «Заведи беклог» — Claude читает проект, предлагает области, ставит `backlog/` и скрипт и
  печатает правило для `CLAUDE.md` или `AGENTS.md`.
- «Перенеси TODO.md и roadmap в беклог» — каждый старый пункт становится задачей или получает
  записанную причину, почему нет; старые файлы уходят в архив с картой «пункт → задача».
- «Где я нужен?», «есть что-то быстрое?», «что взять на ночь?»
- «Запиши идею», «заведи задачу», «то же для другого клиента», «разбери inbox».

Команды за ними:

| Нужно | Команда |
|---|---|
| Новая задача | `backlog.py new api "Заголовок" --p P2 --who claude --auto yes --effort 2h` |
| То же для другой области | `backlog.py port API-001 web` |
| Идея с дороги | `backlog.py idea "текст"` |
| Закрыть | `backlog.py done API-001 ok "что вышло, коммит"` |
| Взять в работу, отпустить | `backlog.py take API-001 "машина, сессия"`, `release API-001` |
| Списки | `backlog.py list --owner`, `--quick`, `--night`, `--area api`, `--tag bug` |
| Отчёт: кто делает, приоритет, блок, стоимость | `backlog.py report --area api,web --p P1,P2 --who alone` |
| Проверка перед коммитом | `backlog.py check` |
| Перенести в другую область | `backlog.py move API-001 web` |
| Новый номер, если один взяли две сессии | `backlog.py reid API-001` |

## Настройки

Всё, что отличает проекты, лежит в `backlog/config.json`: области с префиксами ID, замороженные
области, исполнители и их роли (агент, владелец, другой человек), места, к которым привязана
задача, словарь меток, язык собираемых файлов. Русский и английский встроены, другие языки — через
`labels`. Подробно — [references/config.md](skills/backlog/references/config.md) (на английском).

## Несколько сессий разом

Номер задачи уникален, только когда он запушен. Заводя задачу, скрипт учитывает номера уже
полученной ветки сервера; `check` после слияния говорит о номере, взятом дважды; `reid` даёт одной
из двух задач новый номер. `INDEX.md` и таблицы областей при конфликте не сливают, а пересобирают.
